# LearnSpace E-Learning User Portal

A responsive e-learning dashboard built with HTML, CSS, and JavaScript.

## Features
- Student dashboard with course and progress statistics
- Three sample courses with progress bars
- Continue-learning lesson list
- Mark lessons as completed or incomplete
- Learning progress saved with browser localStorage
- Upcoming assignment reminders
- Responsive mobile and desktop layout

## Run in VS Code
1. Extract the ZIP file.
2. Open the `e-learning-user-portal` folder in VS Code.
3. Open `index.html`.
4. Right-click in the editor and choose **Open with Live Server**.

You can also open `index.html` directly in a web browser.

## Note
This is a front-end demo. Progress is stored locally in the browser, not in an online database.
